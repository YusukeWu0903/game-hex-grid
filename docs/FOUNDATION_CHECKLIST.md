# 六角格戰棋基礎設定清單

本清單整理一般戰棋需要定義與檢查的基礎系統，以目前 Godot 基準版為起點。狀態為「已有」、「需補強」或「玩法待選」。列出項目不代表已授權實作；命中、反擊、高低差、成長等規則需另外決定。

## 目前採用的基準

六角格、整隊輪流回合、兩職業、每人一次移動及一次攻擊／技能或待機；攻擊後行動結束，不可攻擊後再移動。每場戰前恢復 HP／MP。敵我全滅決定勝敗。合法攻擊必中、固定傷害，不使用反擊、裝備或永久死亡。角色周圍五鍵圖示選單是本次已確認的操作調整。

## 第一層 每場戰鬥必須清楚且可靠

| 類別 | 應定義的基礎項目 | 現況 | 建議優先 |
| --- | --- | --- | --- |
| 單位資料 | 穩定 ID、名稱、職業、陣營、HP／MP 上限、移動力、射程、可用行動、存活狀態 | 已有主要資料；單位檢視頁與可見數值說明需補強 | P0 |
| 回合制度 | 先後手、陣營順序、每回合重置、行動後狀態、等待／取消、回合結束確認 | 已有整隊輪流；規則說明與操作教學需補強 | P0 |
| 移動合法性 | 鄰接、成本、剩餘移動、佔格、穿越友軍、阻擋、路徑預覽、移動次數 | 已有成本與佔格；穿越友軍目前禁止、移動後不可撤銷 | P0 |
| 指令選擇 | 選取、移動、攻擊、技能、待機、取消、失效原因、快捷鍵、連點保護 | 已有五鍵環狀圖示、停用提示與收合；使用者實際操作接受待確認 | P0 |
| 攻擊判定 | 目標陣營、射程上下限、消耗、傷害、死亡、執行時重新驗證 | 已有；固定傷害與必中規則需清楚呈現 | P0 |
| 戰鬥資訊 | 玩家／敵人詳細資料、傷害預覽、擊殺提示、技能效果、行動剩餘、威脅範圍 | 有 HP／MP、單次傷害預覽；完整敵方檢視與移動後攻擊威脅範圍未做 | P0 |
| 部署 | 出戰上限、可用名單、出生點、重疊、地形、增減角色、雙方情報、開戰檢查 | 已有穩定角色 ID、部署與出生點不足拒絕；另設出戰人數上限待定 | P0 |
| 結算與重試 | 勝利／失敗、戰鬥中斷、全滅、同時死亡優先規則、重試重置、離開清理 | 已有全滅、重試、狀態隔離；報酬與統計未做 | P0 |
| 鏡頭與地圖操作 | 棋盤縮放、平移、選角置中、回復視野、邊界按鈕避讓、不同解析度 | 已有縮放、重新置中布局及選單避讓；平移與鏡頭追蹤未做 | P0 |
| 存讀與恢復 | 地圖／關卡保存、戰鬥中存檔、載入驗證、版本相容、備份與壞檔提示 | 有地圖／關卡保存與備份；戰鬥中存讀未做 | P0 |
| 基本設定 | 音效、音樂、動畫速度、減少動態、提示延遲、字體大小、快捷鍵重設、設定保存 | 有音效開關與減少動態；音量、動畫速度、按鍵重設及偏好保存未做 | P0/P1 |
| 教學與說明 | 首次操作、五鍵圖例、地形圖例、取消語義、技能消耗、戰鬥規則查詢 | 有情境提示與 hover；獨立教學／規則頁未做 | P0 |
| 可靠性與驗證 | 邊界、連點、中斷、重開、錯誤資料、存讀一致、失效目標、所有結局、性能 | 有核心與場景自動測試；故障注入及更廣關卡測試待補 | P0 |

## 第二層 規則必須先選定的戰術內容

| 類別 | 可選設定 | 現況與決策重點 |
| --- | --- | --- |
| 攻防模型 | 攻擊力、防禦力、物理／魔法、抗性、護甲、最低傷害、浮動傷害 | 目前固定傷害。增加前先定義公式，不能只加欄位而無實際作用 |
| 命中與暴擊 | 命中率、閃避、暴擊率與倍率、機率顯示、隨機種子 | 目前必中無暴擊。隨機命中不是戰棋必備；可保留確定性設計 |
| 反擊與追擊 | 能否反擊、次數、射程限制、MP／彈藥消耗、追擊門檻 | 目前沒有。若加入，傷害預覽必須同時顯示雙方後果 |
| 朝向與包夾 | 面向、背擊、側擊、夾擊、轉向成本 | 目前沒有朝向規則。加入會改變走位價值及單位呈現 |
| 視線與障礙 | 弓箭是否穿山、射線遮擋、友軍遮擋、視野／迷霧 | 現在只按六角距離判定射程。視線與迷霧要分開定義 |
| 地形效果 | 掩體、防禦、迴避、高低差、落差可通行、飛行／涉水、危險地形 | 現有地形只影響移動；視覺厚度不代表高度數據 |
| 控制區域 | 鄰敵是否停止移動、脫離是否受擊、單位阻擋、穿越友軍 | 目前僅有單位佔格。控制區和機會攻擊需選擇是否引入 |
| 技能模型 | 目標類型、範圍形狀、友軍誤傷、冷卻、施放次數、蓄力、移動後可否施放 | 目前兩個單體 MP 技能。AoE／治療／增益與特殊目標未做 |
| 狀態效果 | 增益／減益、持續回合、施加與到期時機、疊加、免疫、淨化、死亡清除 | 目前沒有；必須先統一回合時機，避免各技能自行計時 |
| AI 行為 | 威脅評估、擊殺、撤退、保護、據點、技能使用、治療、難度參數 | 有合法移動與普攻目標選擇；沒有多種行為型態或技能 AI |
| 關卡目標 | 全滅、存活、護送、守點、到達、擊敗特定角色、回合限制、增援 | 目前僅全滅；每個目標需明確勝敗優先與觸發時機 |
| 撤銷與確認 | 移動預覽確認、移動撤回、攻擊二次確認、重播／回合倒轉 | 目前移動提交後保留。是否允許撤回是玩法決策，不應由取消暗中改變 |

## 第三層 若要做成完整戰役才需要的擴充

| 類別 | 項目 | 現況 |
| --- | --- | --- |
| 成長 | 經驗、升級、屬性成長、技能學習、轉職、等級上限 | 沒有完整成長系統 |
| 裝備與道具 | 武器、防具、消耗品、背包、重量／耐久、裝備限制 | 未實作 |
| 戰後規則 | 傷勢保留、復活、永久死亡、戰利品、獎勵、招募 | 目前每場全員恢復；其他方案需明確替換此規則 |
| 戰役進度 | 關卡解鎖、難度、選關、章節、對話、任務記錄 | 有關卡資料選擇，沒有連續戰役進度 |
| 製作工具 | 數值表編輯、敵人／技能編輯、事件觸發器、關卡測試報告 | 有地圖與關卡編輯；其他工具未做 |
| 發佈與相容 | 獨立桌面包、Web、手機、控制器、本地化、存檔遷移 | Windows Godot 專案可玩；其他目標尚未驗證 |

## 建議執行順序

1. 先補「資訊與操作」：敵我單位完整檢視、敵軍移動加攻擊威脅範圍、地形／指令圖例、鏡頭平移與重置。
2. 再補「可靠性」：戰鬥中存讀、偏好保存、結算統計、更多地圖與中斷情境驗證。
3. 再選「戰鬥規則」：保留確定性傷害，或導入攻防／命中；決定是否有反擊、視線與高低差。
4. 根據規則擴充技能、狀態、AI 與多目標關卡。
5. 確定要做戰役後，再加入成長、裝備、獎勵與劇情。

優先順序是建議，不是尚未確認功能的實作承諾。當前已授權且正在完成的變更為角色旁的五鍵環狀圖示介面。
