## 已驗證行為

- 半徑 4 為 61 格，所有格子像素座標轉換往返一致。
- 地形成本、障礙、佔格、繞路與移動上限。
- MP 不足不消耗行動／MP、不造成傷害；技能成功精確扣除 MP 與傷害。
- 弓箭手最小及最大射程、貼身後退尋找射擊格。
- 未選角色不能部署；無玩家與出生點不足不能開始。
- 一回合只能移動一次；取消不偷偷待機、不回復移動。
- 玩家不能在敵方回合下令；敵方尚未全部行動不能直接進入下一回合。
- 新一場回合數回到 1；角色恢復至職業最大 MP 與初始最大 HP。
- 動畫期間連點不再移動；中途離開後舊回呼不改變新場。
- 關卡角色 ID、地圖修改與 JSON 往返保存一致。
- 無效地圖不覆寫有效資料；地圖編輯使關卡暫時不可玩時，關卡仍保留。
- Godot 匯入、主場景啟動與 Start_Game.ps1 -SmokeTest 成功。

## 畫面檢查

已檢查移動範圍、技能範圍與傷害預覽、地圖編輯、關卡編輯、勝敗畫面，以及 1100×720 視窗截圖。棋盤與主要控制可見，長編輯表單可捲動；文字使用系統中文字型。

人工截圖檢查曾發現戰鬥畫面殘留部署說明，已修正；指令按鈕增加當前模式狀態，敵方攻擊後同步更新角色數值，結果頁移除仍可操作戰鬥的誤導提示。

本紀錄的人工檢查為代理對截圖的檢視，不等同使用者接受，也不等同跨裝置可用性測試。

## 已知範圍與限制

- Windows 鍵鼠與本機 RTX 3060 Compatibility 已測；其他平台、Web、手機、控制器、觸控未測。
- 最小視窗 1100×720；高 DPI 與其他中文字型環境未做完整矩陣測試。
- 沒有新的角色美術、劇情、職業、成長、裝備或永久死亡。
- 舊瀏覽器個人存檔未讀取；僅保留與支援地圖 JSON 格式。
- 保存採暫存與備份；磁碟滿、斷電、檔案鎖定等故障尚未做故障注入。
- 使用者可編輯任意合法地圖；AI 在兩張原地圖完成對戰，不代表所有迷宮均有最優策略。
- 未產出獨立遊戲 exe 或 Web 發佈包，可用提供的啟動器或 Godot 編輯器執行。

## 使用者驗收建議

雙擊 Start_Game.cmd，先在自訂地圖部署並完成一回合，確認棋盤比例、文字大小、移動節奏與指令取消是否符合預期。再使用地圖編輯器修改一格、保存並重新開啟。數值與自動測試已通過，視覺與操作是否採用仍以使用者回饋為準。
