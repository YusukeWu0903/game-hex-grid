# 編隊與關卡條件（2026-11-26）

## 玩家流程

主選單選關卡 → 開始部署 → 戰前出戰清單 → 確認出戰並部署 → 放置角色 → 開始戰鬥。每關有候選池、出戰上限與必出角色；候選池可以大於出生點數量，但上限不可超過我方出生格數。必出與保護角色不能取消；部署階段漏放必出角色會阻止開戰。其餘已勾選角色允許不全部放上棋盤，至少一名可開戰。

隊伍新增諾亞（弓箭手 HP11）、賽拉（法師 HP8）、布蘭（騎士 HP17），目前四職業各兩名、共八人。沿用同職業已採用立繪與技能，並非新增獨立美術或職業。新角色可在新任務使用；原關卡保留原名單，編輯關卡可擴充候選池。

裝備仍於主選單整備，本場開始恢復 HP／MP。新隊伍初始武器按八人配置；既有 party.json 不會被重設或贈送額外武器，新角色可使用現有隊伍裝備。角色數值、初始裝備與背包由 Excel 匯出 JSON。

## 關卡工具

關卡編輯器可選候選角色、出戰上限、必出角色、保護對象及勝利條件。保護對象自動包含於必出名單。

| 勝利類型 | 判定 |
|---|---|
| 敵方全滅 | 所有敵人倒下 |
| 擊敗指定敵人 | 指定敵軍序號死亡，其他敵人可以存活 |
| 存活指定回合 | 完成第 N 次敵方回合，清光敵人也須到指定時間 |
| 抵達指定區域 | 任一存活我方抵達中心格半徑內，移動完成判定；部署已在區域內則開戰即完成 |

我方全滅永遠判敗。可另外勾保護對象（任一倒下即敗）與回合上限（0 為不限）。最後一回合可正常行動，敵方回合完成後仍未達標才超時。同時達成勝利與保護對象死亡／我方全滅時，敗北優先；同一回合末存活成功與期限同時滿足則勝利。

指定敵人以陣容序號識別，相同敵人模板可多次出現。刪除目標所在陣容列後需重選，不能靜默把目標換成下一人。抵達區中心使用 x,y,z 立方體座標，三者總和必須為0；中心須位於可走格，半徑0–6，地圖外／不可走格不會成為有效目的地。編輯器棋盤顯示座標，戰鬥以青綠色框標示目的區。

## 示範關卡

保留原邊境演練與遠征試煉，另提供：編隊演習（八選五、全滅）、斬首任務（指定帝國騎士）、守護任務（米菈存活三回合）、突破任務（八回合內抵達中心格）。這些是功能試玩關卡，尚未完成難度曲線與劇情平衡。

## 保存、回溯與戰利品

戰鬥保存保留關卡規則及本場選定名單；回溯還原位置、死亡／擊殺紀錄、回合、道具及掉落，因此任務進度同步還原。靜態條件不在每個回合重複儲存。舊關卡缺少新欄位時仍使用全滅規則與原出戰人數。

勝利條件完成後照既有流程結算本場剩餘戰利品，不會自動取得仍存活敵人的掉落。敗北可以回溯；勝利入庫後封存，避免重複領取。未加入條件 AND/OR 編輯、同盟 NPC、護送 AI、增援、劇情觸發、救援或關卡分支，本輪保護對象限可出戰我方角色。
