# RPG 擴充與回溯規格（2026-11-25）

已確認：Excel 編輯 → 驗證匯出 JSON → Godot 載入；法師與重甲步行騎士；武器／防具／飾品三槽；隊伍道具包；相鄰開箱與使用道具各耗一次行動。勝利才結算戰利品，敗北／重試回復戰前背包。每個我方回合開始留回溯節點，不限使用次數；回復後捨棄未來時間線，還原隨機狀態，勝利入庫後封存。

初版平衡可於表格修改：法師 HP9／MP30／移動3，單體魔彈4MP、射程1–3，烈焰爆破6魔傷／10MP／半徑1、只傷敵人；騎士 HP16／MP20／移動2／物防2，盾牆6MP提高物防魔防3，維持到下次我方回合開始。物理傷害=max(1,招式威力+武器攻擊−物防−盾牆)，魔法改用魔攻／魔防。原職業原始無加成裝備仍保留既有傷害。

道具對自己或相鄰友軍使用，滿資源／無效目標不消耗；戰中不換裝。掉落表每列獨立機率，可掉多項或沒有掉落，物品數量均為整數。暫存戰利品可在本場使用，勝利保存剩餘背包；戰敗不改永久背包。寶箱不阻擋路徑、只能放可走格，生成時避開出生點。

回溯保存單位、裝備效果、HP/MP、位置、行動與防守狀態、背包、暫存戰利品、已開箱、已處理擊殺及 RNG 狀態。靜態地圖不在每個歷史節點重複複製。第1回合在部署完成後建立。恢復歷史會取消現有動畫並清除目標選取。戰鬥保存含歷史；勝利結算以 battle_id 去重，載入已結算的舊戰鬥不得再領獎。

驗收：Excel錯誤指出工作表列號且不覆蓋有效JSON；職業與裝備限制；物魔傷害；無效道具不扣量；AoE單次扣MP；掉落只判定一次；寶箱可編輯生成；回溯第1／中間／當前回合與分歧後結果一致；重開存檔保留歷史；勝利重複結算不重複入庫；最大地圖資源量測。

## 實作與相容性

四職業、八角色、11 件裝備、3 種道具已接入。新關卡「遠征試煉：法師與騎士」展示五人隊伍、法師／騎士敵軍與寶箱。法師與騎士主角第二版正式立繪已採用並接入；新增同職業角色共用立繪。敵軍仍為職業剪影。

V2 戰鬥存檔包含回合歷史；V1 舊存檔仍可讀取，但只能從載入回合建立歷史，無法恢復未記錄的先前回合。單份存檔上限 32 MiB，超限拒絕寫入並保留舊檔；記憶體回溯無次數限制。歷史每回合保存動態狀態，靜態地圖共用。回溯會同步還原亂數，重做相同事件不會重抽寶物。

隊伍庫存與結算紀錄位於 party.json；已結算 battle_id 封存，舊戰鬥存檔不得再次入庫。磁碟寫入失敗時可重試結算，不能將未保存結果當成已入庫。尚未加入商店、合成、裝備詞綴、坐騎或成長系統。

UI 自動化與截圖檢查已執行，仍需使用者試玩接受操作及視覺。新增角色數值與關卡尚需長期平衡試玩。
