# 全畫面戰鬥演出

2026-11-25 使用者確認：全畫面對決，我方在左、敵方在右，先使用劍士／弓箭手持武器職業剪影，正式立繪另行採用。

## 流程與方向

1. 攻擊／技能先經共用規則驗證，無效目標不播放。
2. 成立後只結算一次 HP、MP、死亡與行動旗標；保存攻擊前雙方快照供演出使用。
3. 演出遮住棋盤。0–0.4 秒雙方進場；0.78 秒開始攻擊者突進，約 1.2 秒命中特效與傷害數字，隨後回復姿勢；約 2.65 秒返回棋盤。
4. 我方攻擊向畫面右側突進、敵方受擊；敵方攻擊向左側突進、我方受擊。雙方站位不因攻守交換。
5. 劍士使用斬擊，弓箭手使用箭矢；MP 技能有額外金色效果。擊倒者降透明度並顯示「擊倒」。
6. 玩家最後一擊的勝敗畫面，以及敵人最後一擊／下一回合，均等待演出結束再顯示。

減少動態模式約 0.8 秒，只保留角色、招式與傷害資訊，取消入場位移、突進、閃白和震動。關閉戰鬥演出時沿用棋盤上的傷害回饋。

## 操作與生命週期

- Space、Esc、Enter 或右下按鈕跳過；跳過不撤銷已成立的攻擊，也不再次套用傷害。
- 演出時鎖定棋盤指令及保存；Tab 焦點在演出與跳過按鈕之間循環。
- 離開／重開使 generation 失效並終止演出；舊協程不得更改新戰鬥。
- `ui/combat_cinematic.gd` 只讀雙方快照，沒有修改 BattleSession 的權限或程式路徑。`ui/main.gd` 協調玩家／敵方流程。
- 演出開關、減少動態及音量保存到 settings.json。

## 正式立繪接入

優先使用 `res://assets/portraits/<unit.id>.png`。三名主角的 player_swordsman_01、player_swordsman_02、player_archer_01 已於 2026-11-25 經使用者採用並接入。

若逐名立繪不存在，再使用以下職業／陣營路徑：

- `res://assets/portraits/swordsman_player.png`
- `res://assets/portraits/swordsman_enemy.png`
- `res://assets/portraits/archer_player.png`
- `res://assets/portraits/archer_enemy.png`

素材不存在時使用程式繪製剪影。使用透明 PNG、朝畫面右方、完整保留人物與武器；敵方在畫面右邊由程式水平翻轉。圖像等比例放入 420×470 的設計區域，底部對齊站立線。逐名角色可使用不同素材；尚未建立表情與骨架動畫系統。

正式圖匯入 Godot 並重啟遊戲後生效。

新增正式角色候選仍須先放在專案外，經使用者採用後才匯入這些位置；不要把尚未採用的候選當成正式素材。
