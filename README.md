# Hex Tactics Godot

保留原版六角棋盤與兩職業的 Godot 2D 戰棋基準版。包含關卡選擇、部署、回合戰鬥、AI、全畫面戰鬥演出、敵方威脅資訊、戰鬥續玩、勝敗結算、地圖與關卡編輯及 JSON 匯入匯出。

## 啟動

在 Windows 雙擊 Start_Game.cmd。啟動器使用上一層的 Godot_v4.6.3-stable_win64.exe；其他安裝位置可先設定 GODOT_BIN。也可用 Godot 4.6.3 開啟 project.godot，按 F6 執行 scenes/main.tscn，或 F5 執行整個專案。

這是可在 Godot 中直接執行的專案，尚未製作獨立遊戲執行檔或 Web 發佈包。

## 操作

1. 主選單選擇關卡，按「開始部署」。
2. 點角色後再點我方出生格，或使用「自動部署」；右鍵收回角色。
3. 開戰後點我方棋子或左側角色，從棋子周圍選靴子圖示，再點可達格移動。
4. 劍圖示為攻擊、星芒為技能；選擇後環狀按鈕收起，再點合法敵人。技能需足夠 MP。滑鼠停留圖示可查看詳細說明。
5. 沙漏圖示為待機；左上叉號取消選取。左側「結束我方回合」確認後讓其餘角色待機。
6. 右鍵或 Escape 從瞄準返回環狀選單，再按一次解除選取。取消不待機，也不撤銷已完成的移動。快捷鍵：M 移動、A 攻擊、S 技能、W 待機。
7. 點敵人或已行動的我方查看資料；T 切換全敵軍威脅。紫紅色格預估敵人依目前占位，下次移動後的普攻範圍，並非 AI 必定攻擊的位置。
8. 滾輪縮放、中鍵拖曳平移；F 定位所選角色，Home 重置視角。F1 或右上角 ? 開啟操作與地形說明。
9. 攻擊成立後進入全畫面對決：我方固定在左、敵方在右。Space／Esc 或畫面按鈕可跳過；傷害與 MP 只結算一次。
10. 上方可調整音效、音量、減少動態及戰鬥演出開關；設定會保存。
11. 我方回合、沒有動畫時可按「儲存戰鬥」或 Ctrl+S。主選單「繼續戰鬥」還原進度；有備份時可選「讀取上一份備份」。

玩家普攻 4 傷害，敵方普攻 3；劍士重擊 10 MP／7 傷害，弓箭手強力射擊 15 MP／6 傷害。每場戰前全員恢復 HP／MP。

## 編輯與保存

地圖編輯先修改工作副本，按保存才寫入資料庫。匯入 JSON 先驗證並載入副本；無效地形、座標與出生點會被拒絕。地圖匯出保留原版格式。

關卡編輯使用同一份角色 ID 清單；出生點不足會禁止試玩。現階段只提供敵軍全滅／我方全滅規則。

啟動器將保存及日誌放在本專案 user_data，排除於版本控制。可用 HEX_TACTICS_DATA_DIR 指定其他目錄。保存會保留上一份 .bak。編輯地圖使關卡暫時不可玩時，關卡記錄仍保留，需補足出生點再試玩。

戰鬥保存包含關卡與地圖快照、回合、存活單位、HP／MP、已移動／已行動狀態；讀檔不補血、不補 MP、不重置行動。戰鬥中存檔為 battle.json，偏好為 settings.json。只允許在我方可操作時保存，避免敵軍／演出中途的半完成狀態。格式或資料無效時拒絕載入並保留原檔。

演出目前使用經使用者確認的劍士／弓箭手職業剪影，並非正式角色立繪。正式素材替換規則見 docs/COMBAT_PRESENTATION.md。

原瀏覽器 localStorage 不會自動搬移；可從原版匯出地圖 JSON 後在這裡匯入。

## 規格與維護

- docs/GAME_SPEC.md：已確認的目標玩法、數值、操作及驗收。
- docs/CURRENT_GAME_SPEC.md：原版調查與比較基準。
- docs/MIGRATION_REQUIREMENTS.md：移植需求、實作對應與範圍。
- docs/VALIDATION.md：驗證結果及仍需使用者確認的部分。
- docs/FOUNDATION_CHECKLIST.md：一般戰棋基礎設定、目前狀態與建議優先順序；未確認的規則只列為候選。
- docs/COMBAT_PRESENTATION.md：演出流程、方向、跳過與正式立繪接入約定。
- data/catalog.json：職業、技能、玩家與敵人資料。
- core/：六角規則、戰鬥規則、回合模型與保存。
- ui/：棋盤、介面與音效。
- tests/：規則、整場模擬、保存與實際視窗流程測試。

## 測試

執行 powershell -ExecutionPolicy Bypass -File ./Run_Tests.ps1。預設 UI 測試會短暫開啟實際 Godot 視窗並截圖；可加 -HeadlessUI 只跑無畫面流程。加 `-FullPlaythrough` 會額外使用實際鼠鍵事件完整打完兩張地圖，交錯自然播放與跳過演出（約一分鐘）。測試使用隔離資料，截圖與日誌位於 D:/Codex/visualizations/2026-11-25/hex-tactics-foundation 下的獨立 run 目錄。

目前支援 Windows 鍵鼠，最小視窗 1100×720。Compatibility 渲染器已在本機執行；Web、手機、控制器操作與其他平台尚未驗證。人工檢視截圖不等同使用者已接受畫面與操作。
