## 遊玩與輸入

主選單選「劇情演示：邊境集結」，部署後開戰。示範台詞為可替換草稿，沒有新增世界觀定案。

- Space / Enter：尚在打字時顯示全文；全文顯示後才換下一句。長按的重複鍵不推進。
- H：開啟／關閉歷史；歷史中 Esc 返回同一句，不改變進度。
- 略過本段：確認後結束本次已排入的對話；未顯示完整的句子不列為已讀。
- 旁白不顯示姓名與人物；保留閱讀工具。正文每字 28ms。
- 視窗以比例錨點排版，姓名在正文上方，圖在文字框後方；目前人物一次顯示一位。
- 對話期間封鎖棋盤、鏡頭與戰鬥快捷鍵，不能儲存半段對話。完成後回到原戰況，正常戰鬥存檔保留劇情紀錄。

## Excel 與觸發

`data/tables/GameData.xlsx` 新增「劇情事件」「劇情台詞」，共 16 表。執行 `Export_Data.cmd` 驗證匯出，重新啟動遊戲生效。遊戲只讀 `catalog.json`。

事件表：id、關卡ID、觸發、回合、角色ID、q、r、半徑、劇本ID。關卡ID必須對應欲播放的關卡 `levelId`；可設定自訂關卡。台詞表：id、劇本ID、順序、說話者、立繪、位置、台詞。立繪欄填 `assets/portraits/` 下已採用 PNG 的檔名，不含副檔名。空說話者／立繪為旁白；位置填 LEFT 或 RIGHT。

| 觸發 | 時機 |
| --- | --- |
| START | 部署完成、第一回合開始、接受玩家戰鬥操作前 |
| TURN | 指定我方回合開始；回合 1 也可用 |
| AREA | 我方移動演出完成後抵達指定區域；我方回合其他狀態更新也檢查。角色ID空白代表任何我方 |
| VICTORY | 勝利確定，正式戰利品／經驗結算前 |
| DEFEAT | 敗北確定，結果操作前 |

區域使用軸座標 q/r（第三軸為 -q-r）與六角距離半徑。AREA 只在仍可行動的我方階段成立；抵達同時完成任務時優先播放勝利。多事件同時滿足按事件表列序排列。每事件每場一次；同劇本可被不同事件引用。已讀歷史以台詞 ID 去重。沒有出戰的指定角色不會觸發區域事件。

驗證：事件／台詞 ID 唯一、劇本引用有效、指定角色存在、已採用立繪存在、LEFT/RIGHT、每句 1–160 字、說話者至多 24 字、每劇本至多 128 句且順序不重複、最多 128 事件、座標與半徑在限制內。關卡 ID 可指向使用者將新增的關卡，因此不是全域存在性校驗。

## 存檔、回溯與效能

戰鬥 `story.seen` 與 `story.log` 隨 `round_state`、`export_rpg` 及所有回合快照保存。觸發時先登記，避免重新整理重播；UI 期間禁止儲存，只有完整對話邊界可保存。舊存檔缺欄位時視為空紀錄。載入會校驗事件屬於該關卡、已讀台詞屬於已觸發劇本，拒絕未知／重複 ID。

回合開始快照在該回合事件播放前建立，所以回溯至同回合會重新播放該回合開場；後續回合快照保留先前已讀歷史。戰利品仍只在勝利結算一次，回溯不能越過已結算戰鬥。不要刪除仍被存檔引用的劇情 ID；重命名會使舊快照驗證失敗。

只在開始、行動結束、回合開始、載入及回溯時檢查事件，沒有逐幀地圖掃描。立繪按本次對話快取，結束／取消時釋放引用。UI 隱藏時停止 process。效能與測試結果見 VALIDATION.md。
