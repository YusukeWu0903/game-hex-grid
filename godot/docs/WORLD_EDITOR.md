# 大型戰場與地圖編輯規格

2026-11-25 使用者確認：日式奇幻手繪方向、所有可走區連通、暫無傳送、最大半徑 24（1,801 格）、完整編輯工具及平滑鏡頭。三名主角造型另經使用者明確採用。

## 使用方式

主選單 → 地圖編輯。左側工具可捲動。左鍵按住繪製，中鍵拖曳，滾輪縮放，右下小地圖點選／拖曳定位。藍／紅點標示雙方出生區。

- 六種地形、兩軍出生點、清除出生點。筆刷半徑 0–3（1／7／19／37 格），拖曳跨格補齊路徑；同一次按住拖曳是一筆復原記錄。
- 「填滿同地形區域」以六鄰格連通的原地形為範圍。
- Ctrl+Z／Ctrl+Y 或復原／重做按鈕；最多 60 筆。尺寸修改與生成套用都能復原。檔案名稱修改不列入筆刷歷史。
- 半徑 1–24。縮小時裁去超界地形與出生點；擴大新增平地。套用前保留舊稿於復原記錄。
- 種子 0–2147483647，山水目標比例 0–45%。一鍵生成先預覽，套用才改工作副本；返回編輯內容取消預覽。切換其他編輯工具也回到原稿。
- 儲存／JSON 匯出前檢查規則；編輯中允許不完整草稿。匯入仍先做格式驗證，規則錯誤可以載入修正，但不能保存或匯出。
- 「檢查連通與山水群落」以紅色格與驚嘆號標示孤立區或不足 3 格的山水群落。需要補足出生點才能配置對應人數的關卡。

## 生成契約

使用 Godot FastNoiseLite 的固定種子。先建立全可走地圖，按噪聲排序候選，每次加入同類型至少 3 格的連通山或水。任何會分裂可走區的候選都撤回。已加入的山水不拆散，因此不產生單格障礙；所有陸地維持同一連通區。最後添加森林、丘陵、沼澤及兩側各 3 個不重疊的可走出生點。

山水比例是目標而非保證精確值：群落以 3 格為單位，連通與出生區優先；小地圖可能沒有足夠空間放障礙。相同版本、尺寸、種子與比例可重現相同地圖。generator.version=1 與參數隨地圖保存。舊內建地圖保持原樣，舊檔案仍可載入；重新編輯保存時套用新規則。尚無傳送、橋樑、海軍或高度戰鬥規則。

## 鏡頭與視覺

半徑大於 4 不再縮小整張地圖以適應視窗；保持格子基準尺寸。支援 0.45–2 倍平滑縮放、中鍵平移、邊緣捲動、小地圖、F 定位與 Home 重置。大型地圖選取及移動角色時跟隨，部署時定位我方出生區。戰鬥動畫鎖住手動鏡頭，但允許角色跟隨。

採用草綠、石灰、藍綠水域與古金介面；山峰、森林、水紋等辨識圖樣疊加原生 NoiseTexture2D 材質。這是本輪程序化地形美術，不是外購手繪地圖素材包。三名主角採用手繪日式奇幻立繪，敵方仍用職業剪影。

## 效能設計

六種地形由 SubViewport 一次烘焙為 768×144 圖集；TerrainLayer 保留繪製指令，鏡頭平移縮放只改 Node2D 變換。動態提示只遍歷實際標示格。小地圖以 160×140 圖片快取，編輯時才重建。沒有每格獨立節點或每幀尋路。復原歷史上限 60 筆，效能面板每 0.5 秒更新一次，預設隱藏。

F3 開關效能監視：FPS、Godot 幀時間、Godot 靜態記憶體、VRAM 與 Draw Calls。FPS 上限 60。靜態記憶體不是 Windows 程序總記憶體；部分引擎監視值更新較慢，效能報告另用實際影格間隔統計。報告見 PERFORMANCE.md。

## 驗收與限制

已測半徑 1／4／12／24、32 組種子配置及重現、孤立水格、環狀封閉區、填色、復原與尺寸裁切。實際視窗測試兩端／中央選格、最小／最大縮放、小地圖、生成預覽／套用／復原、拒絕無效保存、1100×720。

仍待使用者實際試玩接受介面密度、鏡頭手感與地圖美術；自動測試不替代視覺接受。未驗證低階 GPU、手機、控制器、長時間遊玩或大量軍團。單次生成目前同步執行，本機最大尺寸約 0.85 秒；未引入背景執行緒生成。
