# 完整關卡流程與分區段劇情

## 試玩入口

主選單選「邊境尋寶：中央的寶物」，按「進入關卡」。四職業、八人候選池、最多五人出戰，艾爾必出。任務寶物暫定「邊境徽章」，為無能力加成、不可消耗的飾品；名稱與示範台詞均可在 Excel 調整。

流程：進入 → 開場區段 → 出戰名單 → 佈陣 → 正式戰鬥 → 開箱區段 → 滿足勝利條件 → 結算畫面 → 確認結算 → 結尾區段 → 返回關卡選單。

敗北：通用失敗區段 → 原因與退出／回溯／重新再戰。重戰返回出戰名單，不強制重播開場，另有重看開場入口。敗北不結算暫存戰利品或經驗。

## 分區段資料

`data/tables/GameData.xlsx` 編輯後用 `Export_Data.cmd` 驗證匯出 JSON；遊戲不直接讀 Excel。目前 18 表。

| 表 | 用途 | 關聯 |
| --- | --- | --- |
| 關卡流程 | 關卡名稱、地圖、指定寶箱、任務寶物、出戰上限 | id 對應 levelId |
| 劇情區段 | 區段 ID、名稱、說明；開場、開箱、結尾、通用失敗分開管理 | id 是事件與台詞共用的區段鍵 |
| 劇情事件 | 關卡、觸發類型、回合、區域／寶箱座標、播放區段 | 區段ID → 劇情區段.id |
| 劇情台詞 | 台詞 ID、區段 ID、段內順序、說話者、立繪、位置、正文 | 同區段依順序播放 |

新關卡區段：`chapter_intro`、`chapter_chest`、`chapter_outro`、`common_defeat`。原演示的五段與台詞 ID 保留。「劇本ID」欄名改為「區段ID」，既有值不變；JSON 的 script_id 保留相容。

INTRO 在選兵之前；CHEST 在指定座標寶箱實際開啟、拿到掉落後；OUTRO 只在結算成功且玩家確認後。DEFEAT 可由不同關卡引用相同通用區段。START／TURN／AREA／VICTORY 仍可用。一次播放一個事件區段，略過只結束目前區段，其他符合條件的區段接續播放。

匯出檢查區段唯一、有台詞、段內排序唯一、引用有效、地圖與寶箱存在、寶物為非消耗裝備、寶箱保證掉落該寶物。流程必須有 INTRO／CHEST／DEFEAT／OUTRO，開箱事件須對應任務寶箱。既有字數與數值限制沿用 DIALOGUE_SYSTEM.md。

## 勝利與事件順序

`CHEST_AND_ALL` 同時要求指定寶箱已開、寶物存在本場暫存戰利品、敵軍全部死亡。任務面板分列開箱狀態與敵軍剩餘數量。關卡編輯器可選此類型並填寶箱座標與寶物 ID。

- 先開箱：暫存必得寶物、播放開箱段落；敵軍仍在則繼續戰鬥。
- 先全滅：不結算，保留操作與回合，直到開箱；仍可存讀檔。
- 開箱是最後目標：先播開箱段落，再結算。
- 回溯到開箱前：還原寶箱、背包、暫存寶物、亂數與觸發紀錄；再開箱會重播。
- 敗北規則優先於勝利。新關卡預設我方全滅敗北，無回合期限；既有保護死亡／超時設定仍可使用。

## 保存與恢復

- `chapter_entry.json` 保存 INTRO／SQUAD／DEPLOY 階段、地圖、名單與部署位置。狀態改變才寫入，同內容 UI 刷新不重寫。選單的「繼續戰前劇情／佈陣」恢復此進度。
- 開場中斷從區段起點重播，不精確到打字字元。選兵與部署還原名單與出生格。
- 正式開戰建立一次戰鬥存檔並消耗戰前進度；後續沿用手動儲存／回合回溯，不逐行動強制寫磁碟。
- 背包、經驗、已結算戰鬥 ID 與 `pending_ending` 同一次原子保存。結算失敗可重試，結尾按鈕不可用。
- 結算後或結尾中重啟，選單提供「接續已結算的結尾劇情」，從區段開頭播放，不再領獎。待播結尾未完成前不能開始另一關覆蓋進度。
- 結尾結束／略過後，成功清除 pending_ending 才返回選單；保存失敗留在重試畫面。結算後不能回溯。
- 戰前快照有大小上限，驗證地圖、名單、出生位置與劇情紀錄。無效資料不套用，原檔保留。
